# Duplicate-job-listings
This is a SQL algorithm designed to scan posting data, identify duplicate job listings that share identical titles and descriptions within the same company, and return the unique company count. The logic and solution of this algorithm were developed entirely through my own efforts and knowledge, without the assistance of any AI tools.
